# ASM-000 — Atlas Scientific Method

**Estado:** Working Method  
**Versão:** 0.1  

## Finalidade
O ASM governa como perguntas, hipóteses, conceitos, modelos e implementações entram no Project ATLAS.

## Princípios
1. Toda a investigação começa por uma pergunta.
2. Todo o conceito nasce provisório.
3. Toda a arquitetura implementa uma hipótese ou decisão explícita.
4. Toda a implementação é experimental.
5. Nova evidência pode alterar o modelo e o quadro teórico.
6. Uma implementação funcional não valida uma teoria.
7. Toda a teoria permanece revisável.
8. Nenhuma hipótese amadurece sem crítica formal.
9. A literatura é confrontada por capacidade explicativa, não por semelhança de nomes.
10. O Foundational Document é ponto de chegada, não ponto de partida.

## Ciclo obrigatório
```text
IQ → IC → Research Mission → RN → Contraexemplos → Literatura → DR → FD → Modelo → Implementação → Validação → Revisão
```

## Quatro perguntas mínimas
1. Que fenómeno está a ser observado?
2. Que condições parecem necessárias?
3. Que condições poderiam ser suficientes?
4. Que observação destruiria a hipótese?

## Regra de implementação
Nenhum módulo novo entra no SRIS sem indicar problema, hipótese/decisão, componente do SMK e evidência que permitirá recolher.
