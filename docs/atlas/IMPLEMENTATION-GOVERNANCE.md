# Governação da Implementação

## Regra de entrada
Nenhuma funcionalidade nova entra no SRIS sem problema, hipótese/decisão, componente SMK afetado, teste e atualização do Registry.

## Classes
A documental · B funcional limitada · C integração · D metodológica · E núcleo crítico.

## Kernel protegido
Proveniência, histórico, autoridade, permissões, ontologia central, lifecycle, aceitação de evidência, auditoria e retenção não podem ser alterados automaticamente sem aprovação humana.

## Evolução governada
```text
Observação → hipótese de melhoria → proposta → sandbox → testes → revisão → deploy → monitorização → aprendizagem
```

## Agentes de IA
Podem propor; não aprovam a própria proposta; não alteram produção diretamente; não apagam logs; não reduzem testes; não criam autoridade.
