# Project ATLAS operational consolidation

## Decision

The GitHub repository is the official source of truth for Project ATLAS.
State: adopted.
Affected: ATLAS, ASM, TICC, SMK, SEE, SRIS.

## Hypothesis

Institutional justifiability may be a mechanism that supports institutional reconstructability.
State: candidate.
Affected: TICC, SEE.

## Risk

Scientific and architectural content that remains only in conversations can be lost or become contradictory.

## Action

Every structural update must produce a registry entry, a scientific changelog entry and an explicit human-reviewed pull request.
