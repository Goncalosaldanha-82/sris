# MISSION-001 — Natureza do Conhecimento Institucional

**Estado:** Planned / ready to start  

## Questão
> Que elementos mínimos têm de sobreviver para que uma equipa futura consiga reconstruir justificadamente o conhecimento necessário para agir?

## Hipóteses candidatas
- Conhecimento como capacidade relacional.
- Trajeto de justificação como objeto relevante de preservação.
- Tetraedro de reconstrução: evidência, lógica/raciocínio, autoridade e contexto.

## Testes de refutação
- Uma equipa recebe todos os elementos e não consegue reconstruir a decisão.
- Conhecimento tácito indispensável não é substituível por artefactos.
- Equipas diferentes produzem reconstruções incompatíveis.
- A literatura existente explica totalmente o fenómeno.

## Entregáveis
Taxonomia de trabalho · contraexemplos · literatura · decision report · impacto arquitetural · definição fundacional apenas se justificada.
