# Experiências

**Finalidade:** Protocolos, casos, dados, resultados e limitações.

## Regras

1. Cada ativo deve ter identificador, versão, estado e data.
2. Nenhum ativo é apagado silenciosamente.
3. Alterações estruturais devem preservar genealogia.
4. Hipóteses não podem ser apresentadas como evidência.
5. Conteúdo aprovado deve ser registado no Registry.
