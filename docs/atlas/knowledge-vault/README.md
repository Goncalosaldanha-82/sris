# ATLAS Knowledge Vault

O Knowledge Vault é a camada de memória institucional transversal do Project ATLAS.

Não substitui as pastas especializadas. Liga-as.

## Funções

- manter o índice mestre do conhecimento;
- preservar genealogia e contexto;
- registar dependências entre ativos;
- indicar o estado epistemológico de cada elemento;
- impedir duplicações e contradições silenciosas;
- permitir reconstrução do percurso de investigação e desenvolvimento.

## O que entra aqui

- mapas de conhecimento;
- índices consolidados;
- snapshots de estado;
- linhas temporais;
- matrizes de dependência;
- relatórios de coerência;
- resumos de transição entre versões.

## O que não entra aqui

- código-fonte;
- dados brutos não classificados;
- documentos finais sem ligação ao Registry;
- conteúdo não revisto apresentado como adotado.
