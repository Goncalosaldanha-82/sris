# ATLAS OS Integration Pack v0.1

Fluxo integrado:

```text
Intake → triagem → revisão humana → materialização → proposta de commit
```

Inclui API FastAPI, base SQLite local, Review Center web, testes e workflow GitHub.

## Arranque

```text
scripts/START_ATLAS_OS.cmd
```

## Limite

É um MVP integrado. Ainda não inclui autenticação, PostgreSQL, RBAC, object storage, workers ou GitHub OAuth.
