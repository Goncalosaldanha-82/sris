# Aplicação ao repositório

Copiar o conteúdo desta pasta para a raiz do repositório, preservando os caminhos.

```bash
git checkout feature/ske-core
git add PROJECT-STATE.md docs/atlas
git commit -m "Consolidate Project ATLAS scientific and architectural state"
git push origin feature/ske-core
```

Antes do merge, confirmar conflitos e preservar todos os ADR e Research Notes existentes.
